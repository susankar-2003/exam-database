1. How many meaningful English words can be formed using the letters 'E', 'A', 'T' using each letter only once in each word?

A) One 
B) Two 
C) Three 
D) Four 
Ans: C

2. If the letters of the word "HANDS" are arranged alphabetically, how many letters will remain in the same position?

A) None 
B) One 
C) Two 
D) Three 
Ans: B

3. Which of the following words CANNOT be formed using the letters of the word "INTERNATIONAL"?

A) TRAIN 
B) NATIONAL 
C) RATIONAL 
D) TERMINAL 
Ans: D

4. Which of the following words CAN be formed using the letters of the word "RECOMMENDATION"?

A) MEDICINE 
B) REMINDER 
C) NATION 
D) DISTANCE 
Ans: C

5. How many meaningful English words can be formed using the 2nd, 3rd, 4th, and 5th letters of the word "HEART"?

A) One 
B) Two 
C) Three 
D) Four 
Ans: C

6. Which of the following words CANNOT be formed using the letters of the word "MAGNIFICENT"?

A) MAGIC 
B) FAINT 
C) CEMENT 
D) GIANT 
Ans: C

7. If in the word "MOTHER", vowels are replaced by the next letter and consonants are replaced by the previous letter in the English alphabet, which letter will be 3rd from the left?

A) L 
B) P 
C) S 
D) G 
Ans: C

8. If each vowel in the word "COMPUTERS" is changed to the next letter in the English alphabet and each consonant is changed to the previous letter, how many vowels will be present in the new word?

A) One 
B) Two 
C) Three 
D) None 
Ans: A

9. If the first and second letters of the word "DEPRESSION" are interchanged, similarly the third and fourth, fifth and sixth, and so on, which letter will be 7th from the right end?

A) E 
B) R 
C) P 
D) S 
Ans: C

10. How many meaningful English words can be formed using the letters 'O', 'N', 'E' using each letter only once?

A) One 
B) Two 
C) Three 
D) Four 
Ans: B

11. Which of the following words CANNOT be formed from the letters of the word "KNOWLEDGE"?

A) GOLD 
B) LODGE 
C) KNOWN 
D) EDGE 
Ans: C

12. How many letters in the word "BEAUTIFUL" occupy the same position when the letters are arranged in alphabetical order from left to right?

A) None 
B) One 
C) Two 
D) Three 
Ans: B

13. If the letters of the word "BENEFIT" are arranged in alphabetical order, how many vowels will change their positions?

A) None 
B) One 
C) Two 
D) Three 
Ans: C

14. If the first 4 letters of the word "ANTHROPOLOGY" are reversed, then the next 4 letters are reversed, and the last 4 letters are reversed, which letter will be 8th from the left end?

A) P 
B) O 
C) R 
D) Y 
Ans: C

A) PAPER
B) REPARTITION
C) NATION

A) O
B) C

A) None 
B) One
